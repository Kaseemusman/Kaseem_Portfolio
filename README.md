# Kaseem Usman Portfolio Website

This is a responsive personal portfolio made with HTML, CSS, and JavaScript.

## Included files

- `index.html` — website structure and content
- `styles.css` — colors, layout, hover effects, animations, and mobile styling
- `script.js` — mobile navigation, section animations, active links, and copyright year
- `README.md` — setup and editing instructions

## How to open the website

1. Extract the ZIP file.
2. Open the `kaseem_portfolio` folder.
3. Double-click `index.html`.
4. The website will open in your browser.

## Information to update before publishing

Search inside `index.html` and change:

- `your-email@example.com`
- LinkedIn profile link
- GitHub profile link
- Education details if needed
- Skills and project descriptions
- Future certifications and experience
